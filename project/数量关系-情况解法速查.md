## 总纲：因题择法，别把一招当万能

数量关系没有万能首选。先给题定性，再匹配工具（这是被用户纠正过的核心教训——不是代入法优先，有些题不适合代入）：

- **数字推理** → 作差 / 递推 / 拆列 / 数位，**不代入**。
- **选项即所求、可反向验证** → 才用代入（如定序求值题）。
- **整除特征明显**（人数、倍数、分数化最简） → 整除砍项。
- **工程** → 赋值法（总量设公倍数）；**行程** → 比例 / 追及 / 画图；**最值** → 最不利 +1；**周期/同余** → lcm 找重合点。
- **符号说人话**：写「甲＋乙＝100」不写「甲乙＝100」。
- **先看选项差距再定精度**：差距大 → 粗估 1 个即可；差距小 → 最多精算 2 个；**禁止四个选项全算**。
- **算完三回看**：回看首位防数位颠倒、回看单位防万元/亿元、回看方向防增速看反。

**每类题通用选法路径**（以行程为例，其余类同）：先画图/列式定结构 → 认情况直接套式 → 条件不足或求比值 → 比例法/特值法 → 复杂多段 → 画图＋方程。

## 一、数字推理（9 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 等差 | 一阶差恒定，直接补缺 |
| 等比 | 相邻项比值恒定 |
| 二级 | 做一次差（或比）后，新数列呈等差/等比 |
| 递推 | 形如 aₙ=aₙ₋₁+aₙ₋₂×k，用多组验证再推 |
| 幂次 | n²、n³ 加修正项 c，分别找底数与修正项规律 |
| 分数 | 分子、分母分别成规律；或通分后统一观察 |
| 多重(交叉) | 奇偶项分开成规律，或两两、三三分组观察 |
| 多级运算 | 依次试一阶差、和、积、商，找稳定运算规律 |
| 数阵 | 按行、列、对角、外围找和积差商关系 |

**技法库实战补充**：等差首差异常别被带偏（差恒定的才是等差）｜忽大忽小、正负交替看一次差（常是公比为负的等比）｜快增试倍乘、修正找幂次，别忽略修正项｜分数先还原成统一分母再找规律，别用约分后的形式｜大小强弱交替拆奇偶，别混着看｜数阵用完整行定系数再代，别跨行乱凑。

## 二、计算技巧（7 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 尾数 | 只算末位数字（0–9），末位唯一对应选项 |
| 首数 | 分子分母各取前 1–2 位估算，定出首位 |
| 等差求和 | 和=(首项+末项)×项数/2；项数=(末−首)/公差+1 |
| 等比求和 | S=a₁(1−qⁿ)/(1−q)（q≠1） |
| 平方差 | a²−b²=(a+b)(a−b) |
| 裂项相消 | 1/[n(n+1)]=1/n−1/(n+1)，逐项相消 |
| 凑整换元 | 把重复出现的部分设为 t，提取公因式凑整 |

**技法库实战补充**：等差求和 + 整除砍项联用（「奇数人成等差」+ 给出剩余确定数 → 和=项数×中项，找整除）｜分数比较用分数比较法（首数/交叉），别逐项除。

## 三、和差倍比（12 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 基础关系 | 设一份为 x，按倍数关系列出各量，再代入和差 |
| 方程法 | 设关键量为 x，其余量用 x 表示，列等量关系解方程 |
| 方程与不等式 | 整数约束：先列方程消元得差值关系，再用大小序列不等式夹逼，锁定唯一整数解后回验 |
| 比例分配 | 总份数求和，每份=总量÷总份数，再乘各自份数 |
| 年龄 | 年龄差恒定不变，倍数关系随时间改变 |
| 抓不变量 | 找不变量（和不变/差不变/某量不变），统一其份数 |
| 占比求总量 | 总量=部分量÷占比；占的是剩余部分时先算剩余量再反推 |
| 算术平均 | 平均数=总和÷个数 |
| 中位众数 | 中位数=排序后居中数（偶数取中间两数平均）；众数=出现次数最多 |
| 加权(混合)平均 | 总总量÷总份数；或十字交叉求各部分权重比 |
| 平均数变化 | 新总和=原总和±加入数，再除以新个数 |
| 比例归一 | 多个比例同以同一对象为参照：全换成该对象的倍率；两总量之比＝倍率之积，用实际差额定「1 份」→ 总量回代选项 |

**技法库实战补充**：多量和 + 含该量连串和式 + 大小顺序 → **选项即所求就代入**，验顺序封解（见方程就硬解是坑；警惕「不能确定」陷阱）｜两方案 +「最多/至少」→ 范围先卡、整数定选项｜「400多名」区间 → 统一设元写总量式，用区间+整数卡边界｜两百分比比例 + 总费用差 → 总费比=人数倍率×人均倍率，别把倍率方向搞反｜多占比 +「A 比 B 多具体量」→ 先补未知占比，再用占比差对应具体量反推｜两类对象各有倍数关系 + 两个总量 → 分维度独立设元，别混用一个未知数。｜**同余问题**（每 a 个分余 r、每 b 个分也余 r，余数相同）→ N−r 是 lcm(a,b) 的倍数，代入选项验证（2026-11-20 实测，见导图「和差倍比 > 同余问题」）。

## 四、日期周期（5 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 星期推算 | n mod 7；平年 365≡1、闰年 366≡2 |
| 闰年判断 | 能被 4 整除，且（不能被 100 整除 或 能被 400 整除） |
| 周期循环 | n mod 周期长度，余数对应项（余 0 为周期最后一项） |
| 钟表夹角 | 分针 6°/分、时针 0.5°/分，夹角=\|30h−5.5m\|（取 ≤180°） |
| 间隔天数 | 按月累加，注意大小月与 2 月天数；同日期用年差换算 |

**技法库实战补充**：「某月有 5 个周 X」→ 31 天月有 3 个星期几出现 5 次，据此定位月初｜每周固定日做事 + 两类交替 → 由次数定月初起点，再顺推，别把交替起点搞错。｜同余（余数相同）类若问「每 a 个分余 r、每 b 个分余 r」理解为同余，归和差倍比「同余问题」；若问「第 n 个是什么」的循环对应，归本节周期循环。

## 五、工程问题（6 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 给定时间 | 总量设为 t₁、t₂ 的最小公倍数（或 1），效率=总量÷时间，合作效率相加再求时间 |
| 给定效率比 | 总量一定时时间与效率成反比：效率 3:2 → 时间 2:3 |
| 效率比例 | 只给人数/机器数比例时，设人数或效率为特值 1，总量=效率×时间 |
| 中途加减 | 分段列式：各段工作量=该段参与主体效率之和×该段天数，总量守恒 |
| 牛吃草 | 总量=(牛吃速−草生长速)×天数；列两式相减先求生长速，再求牛吃速 |
| 交替工作 | 一个周期工作量=各主体效率之和，总量÷周期量求整周期数，余量按顺序分配 |

**技法库实战补充**：单独完成天数 + 分段合作 + 效率变化 → 赋值总量为公倍数，效率整数化，别让效率分数算崩｜「N 台设备可用 M 天」中途增减 → 按台·天归一，增减后记得重算｜问 x 与 y 的关系式（非具体值）→ 设效率为 1，按守恒化简，别硬求具体值｜多阶段 + 中途人员进出 + 给半程节点 → 用「同一工作量两种表示」建等式，阶段别划错。

## 六、行程问题（7 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 相遇 | 相遇时间 t=路程和÷速度和；相遇点距任一端=该端出发者速度×t（同时出发时） |
| 追及 | 追及时间 t=路程差÷速度差；追上点位置=快者速度×t（快者比慢者多走的正好是路程差） |
| 流水行船 | 顺=船+水、逆=船−水；船速=(顺+逆)/2，水速=(顺−逆)/2 |
| 火车过桥/错车 | 过桥路程=桥长+车长；错车路程=两车长之和，相向用速度和、同向用速度差 |
| 平均速度 | 等距离平均速度=2v₁v₂/(v₁+v₂)，≠ 速度的算术平均 |
| 环形 | 同向追及：路程差=n×周长（速度差）；反向相遇：路程和=n×周长（速度和） |
| 发车间隔 | 车身间距=车速×发车间隔，用车速±人速的相对速度列式 |

### 深度：行程解法体系（原专篇 · 2026-11-11 并入）

**0. 三问定型（任何行程题）**
- 谁在走？几个主体？同时出发还是先后？
- 方向：同向（追及）/ 相向（相遇）/ 折返 / 环形 / 顺逆流？
- 问什么：时间 / 路程 / 速度 / 位置？
- **画线段图（数轴）是万题第一步**：标起点、终点、折返点、相遇点。多段过程（折返/往返/换人）必须画，一画就通。

**A. 基础五法（通用）**
- 线段图法：把运动画成数轴，方向距离一目了然。
- 公式法：s=v×t 三量互求；认出模型直接套 B 的固定公式。
- 方程法：设未知量，按「同一路程 / 同一时间 / 总量守恒」列等量——多主体多段时最稳。
- 比例法：同时同地出发 → 路程比=速度比；同一路程 → 速度与时间成反比（秒杀提速利器）。
- 特值赋值法：路程未知 → 设全程=1 或公倍数；速度比 → 直接赋值（如 v=3、v=5）。

**B. 模型公式（认出模型直接套）**

| 模型 | 公式 |
|---|---|
| 相遇 | t=路程和÷速度和；相遇点距任一端=该端速度×t（同时同起点） |
| 追及 | t=路程差÷速度差；追上点位置=快者速度×t |
| 环形 | 同向追及：路程差=n×周长；反向相遇：路程和=n×周长 |
| 流水行船 | 顺=船+水；逆=船−水；船速=(顺+逆)/2，水速=(顺−逆)/2 |
| 火车过桥/错车 | 过桥=桥长+车长；错车=两车长和（相向速度和/同向速度差） |
| 发车间隔 | 间距=车速×间隔；人对车用相对速度 |
| 平均速度 | 等距离平均=2v₁v₂/(v₁+v₂) ≠ 算术平均（往返/上下坡最爱考） |
| 折返相遇 | 同向段求速度比（=当时路程比）→ 折返后相向合走原路程差，按速度比分 |

**C. 进阶技法**
- 相对运动总纲：一切模型都是相对速度——相向=速度和、同向=速度差；把一个物体当静止看。
- 整体法：物体折返来回跑（狗在两人间穿梭）→ 不追路径，总路程=总时间×速度。
- 单位换算：m/s↔km/h ×3.6；分钟/小时先统一再算。
- vt 图象（进阶可选）：复杂变速题画 v-t 图，面积=路程。

**D. 选法路径（一句话）**：先画图 → 认模型套公式 → 条件不足或求比 → 比例法/特值 → 复杂多段 → 画图+方程。

**易错清单**
- 往返平均速度 ≠ 算术平均（用 2v₁v₂/(v₁+v₂)）。
- 追及求「追上点位置」=快者速度×t，别拿路程差当位置。
- 火车过桥要加车长；错车是两车长之和。
- 流水的「船速」是静水速度，顺/逆是合成速度。
- 先确认是否同时出发——不同时先算先行距离。

**技法库实战补充**：同向出发 + 一人到端点折返 + 问相遇位置 → 先定速比，折返后转相向相遇，别把折返前后混算｜两人往返跑道问第 n 次追上 → 追上=多跑整数个往返圈，圈数别算错｜上下山同路段两段时间 + 半程位置 → 设段长，用时间反推速度，别混同上下山速度｜环形跑道多人同向两时刻超前/落后 → 用时间比与行程比列式，方向别搞反。

## 七、经济利润（6 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 基本互求 | 利润=售价−成本；利润率=利润/成本；售价=成本×(1+利润率) |
| 打折 | 最终价=原价×(1+涨幅)×折扣率；利润率一律对成本计算 |
| 多件 | 总利润=Σ(单件利润×数量)，或=总销售额−总成本 |
| 分段计价 | 分段累加：各段单价×各段用量（水电、停车、话费阶梯） |
| 盈不足 | 假设全为一种，总差额÷单项差额=另一类数量 |
| 保利润求折扣 | 最低售价=成本×(1+目标利润率)，折扣=最低售价÷标价 |

**技法库实战补充**：表格给标价/折扣/等级率 + 问「哪个最多」→ 写统一公式逐项算，别逐项口径不一｜前后两批售价不同 +「后比前少几分之几」→ 各写利润式，按分数比例列方程，别把「少几分之几」的基准搞错。｜利润率一律对成本算，别拿售价当分母。

## 八、溶液问题（5 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 基础 | 浓度=溶质/溶液；溶质=溶液×浓度 |
| 混合 | 混合浓度=溶质之和/溶液之和（≠ 浓度的简单平均） |
| 加水蒸发 | 溶质守恒、溶液量改变，列守恒式求新浓度 |
| 等量交换 | 交换后两杯溶质总量不变，逐杯按溶质/溶液重算浓度 |
| 十字交叉 | 质量比=(混合浓度−低浓度):(高浓度−混合浓度) |

**实战补充**：混合/加水蒸发抓「溶质守恒」这条主线；十字交叉后注意比值方向（质量比对应浓度差的反比）。

## 九、排列组合（10 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 分类分步 | 分类用加法原理，分步用乘法原理 |
| A/C | A(n,m)=n!/(n−m)! 与顺序有关；C(n,m)=n!/[m!(n−m)!] 与顺序无关 |
| 捆绑 | 相邻元素捆成一个整体参与排列，整体内部再排序 |
| 插空 | n天选k场两两不相邻：C(n−k+1,k)；隔 m 天变式 C(n−(m+1)(k−1),k) |
| 隔板 | 相同球入 m 盒至少 1 个：C(n−1,m−1)；允许空盒先每盒预借 1 个再减 |
| 定序去重 | 总排列数 ÷ 固定顺序元素的内部排列数 |
| 错位 | Dₙ=(n−1)(Dₙ₋₁+Dₙ₋₂)；D₄=9、D₅=44（全不配对） |
| 环形 | 圆排列=(n−1)!（先固定一个位置破环） |
| 涂色 | 从相邻最多的区域入手，分类讨论或总排列去重 |
| 分组分配 | 均匀分组先除以组数阶乘，再乘分配对象数 |

**技法库实战补充**：每个对象独立选一位置 +「每位置至少1个」→ 先 mⁿ 再减去空位，别忘减｜选 k 个互不相邻 → 折叠成从 n−(k−1) 中选 k，折叠量别算错｜有「多面手」可兼两类 + 每队供需固定 → 先锁总人数再按多面手去向分类，别重复计数。

## 十、概率问题（4 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 基本概型 | 古典：P=满足条件的情况数 ÷ 总情况数 |
| 事件关系 | 独立事件 P(AB)=P(A)P(B)；互斥 P(A+B)=P(A)+P(B) |
| 模型应用 | 比赛获胜：逐场独立概率相乘、分类求和；注意提前结束不补赛 |
| 综合 | 期望：E(X)=Σ(取值×对应概率) |

**技法库实战补充**：每人抽固定题数 +「恰有 k 题没被抽到」→ 分母 C(n,m)^人数，分子用占位计数，别漏算覆盖｜结果概率取决于某事件发生与否 + 各给条件概率 → 全概率加权求和，别漏加权。

## 十一、几何问题（9 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 平面面积 | 三角形=底×高/2；梯形=(上底+下底)×高/2；圆=πr² |
| 立体体积 | 柱体=底面积×高；锥体=底面积×高/3；球=4πr³/3 |
| 相似缩放 | 相似比 k → 面积比 k² → 体积比 k³ |
| 周长面积最值 | 周长一定时正方形面积最大；面积一定时正方形周长最小 |
| 勾股 | a²+b²=c²；常用 3-4-5、5-12-13、6-8-10 |
| 三边关系 | 两边之和>第三边，两边之差<第三边 |
| 网格最短路 | 只能朝目标方向走，走法数=C(总步数, 横向步数) |
| 展开最短 | 把相关面展开成平面，两点连线取直线距离 |
| 对角线分块 | 对角线交点把四边形分成四块，对角两块乘积相等：S₁·S₃=S₂·S₄ |

**技法库实战补充**：从一点观测两目标给方位角和距离 + 求间距 → 先算夹角判三角形形状，方位角方向别错｜四边形被对角线分四块 + 给各块面积关系 → 用「对角两块乘积相等」定理，别用错定理。

## 十二、最值问题（8 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 和定积最大 | 两数越接近积越大，相等时最大（均值不等式） |
| 二次函数 | y=ax²+bx+c 在顶点 x=−b/(2a) 取极值 |
| 抽屉 | 最不利情况数 + 1 |
| 构造数列 | 其余项按大小取边界极端值，据总和倒推目标项 |
| 非典型最值 | 约束最优化：找绑定约束与产能联立，产量取可行域顶点 |
| 统筹 | 能并行则并行，识别瓶颈环节、压缩关键路径 |
| 运输配比 | 比较单位载重成本，尽量满载、避免空驶 |
| 空瓶换水 | 先买后喝再换，递归计算或用总量公式（允许借瓶时更快） |

**技法库实战补充**：「至少取…才能保证…」→ 最不利原则：先构造最坏不达标态再 +1，最坏态别构造不全｜「保证出现 A 或 B」→ 找同时不满足 A 和 B 的最大取法再 +1，别只防一个条件｜「至少 k 人答对」+ 分数互异 + 无人满分 → 算总量用极值分配定上界，极值方向别错｜两产品各有正负资源消耗 + 资源下限 + 总量上限 → 写约束求边界点，别列漏约束｜多任务串行 + 等待/存放费用 → 短作业优先排（升序），别按长作业排。

## 十三、容斥原理（4 情况）

| 情况 | 公式 / 做法 |
|---|---|
| 两集合 | \|A∪B\|=\|A\|+\|B\|−\|A∩B\| |
| 三集合 | \|A∪B∪C\|=Σ\|A\|−Σ\|A∩B\|+\|A∩B∩C\| |
| 文氏图 | 画文氏图，从三交区向外交逐层求出各区域 |
| 极值 | 交集最大=各项之和−总数；最小用反向最不利法 |

**技法库实战补充**：「点赞/收藏」两类 + 都做的交集 + 都没做的 → 标准两集合容斥（A+B−交集+都不=总数），交集别重复计｜两属性交叉分类（性别×党籍）+「某项相同」→ 补全总数后锁交叉格，交叉格别算错。
