解析结构 UI 原型 · 以「26年省考35季 第53题」为例

旧结构：解法 / 步骤 / 深度解析 / 选项排除 → 4 个平铺 Tab，一次只能看一个，来回切换。

新结构：改为「分层解析流」——一句话解法 → 解题路径 → 选项判定 → 深度解析，一屏纵向读完，顶部锚点跳转。

新结构相比旧 Tab 的改进点

  • 不用切换：四类解析纵向连成一条"解题流"，滚动即读，降低来回点 Tab 的认知负担。
  • 结论前置：一句话解法置顶高亮，先给答案与方法，再看推导，符合"先结论后论证"的阅读习惯。
  • 步骤可视化：时间线 + 序号 + 连接线，关键步骤（锁定答案）用绿色高亮；"逐步讲解"可一步步揭示，适合教学。
  • 判定修正：选项按"是否答案"区分保留/排除两色（修正了旧渲染里 A 也被标成红色排除的问题）。
  • 解析结构化：深度解析按体系定位/识别信号/本质/通式/易错链拆成标签行，通式用代码块、易错用警示块。
  • 锚点导航：顶部 sticky 导航，长解析可一键跳到目标层次。
